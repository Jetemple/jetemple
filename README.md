### Projects

- **[LiteLLM](https://github.com/BerriAI/litellm/pulls?q=is%3Apr+author%3AJetemple+is%3Amerged)**: open-source LLM gateway. [5 merged PRs](https://github.com/BerriAI/litellm/pulls?q=is%3Apr+author%3AJetemple+is%3Amerged) from production use: SSO fixes, UI theming, non-root Docker paths, and structured JSON logging.
- **[agent-rules](https://github.com/Jetemple/agent-rules)**: dogfooded operating manual for coding agents (rules, workflows, a semantic-recall CLI).
